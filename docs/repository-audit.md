## 本项目新增的核心问题

1. 留学习地、第三地、回国三条路线的资格与现金比较。
2. 在读、毕业前、毕业后、已回国四个入口。
3. 学业、身份、招聘、生活四类日期的依赖关系。
4. 每国或地区的政府路径、学校资源、招聘与材料差异。
5. 当前工作权利与未来雇主担保分别核验。
6. 海外学位日期、国内招聘范围、学历认证与到岗衔接。
7. 不同地区的样本分组、阶段事件台账和申请障碍诊断。
