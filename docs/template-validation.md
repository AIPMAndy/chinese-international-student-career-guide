## 已完成检查

工作簿使用 `@oai/artifact-tool` 生成和重算。公开版本不含个人申请资料、证件、客户信息、虚构Offer或测试记录。所有输入区为空白；公式区保留公式。无宏，无工作表保护。

| 输入变化或边界 | 实际结果 |
| --- | --- |
| 申请台账完全空白 | 跟进状态保持空白 |
| 岗位ID已填、跟进日期空白 | 显示“缺跟进日期” |
| 已填跟进日期、复盘日期空白 | 显示“缺复盘日期” |
| 跟进日期等于复盘日期 | 显示“待跟进” |
| 当前阶段改为拒绝 | 显示“已结束” |
| 路线工作资格为不符合 | 显示“暂停此路径” |
| 工作资格符合、担保待确认 | 显示“先核验资格” |
| 资格、担保和证据已填 | 仅显示“可继续核对岗位” |
| 一次性成本真实为0 | 0被保留，预算月数正常计算 |
| Offer 固定收入真实为0 | 0被保留，可支配金额可为负 |
| 修改换算汇率 | 换算后金额相应变化 |
| 本人可到岗日晚于雇主要求 | 显示“需协调入职日” |

以上 12 项测试完成后，临时数据全部清除，重新计算并导出。公式错误扫描未发现 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A`、`#NUM!`、`#NULL!`、`#SPILL!` 或 `#CALC!`。

已检查 XLSX ZIP 结构、9 个工作表名称、公式存储、无错误单元格、无 VBA。申请台账冻结首8行和首列，导出后的冻结位置为 `B9`。表格筛选与下拉验证保存在文件内。

已渲染全部 9 个工作表的首屏、宽表右侧字段和使用说明，检查中文字体、标题、表头、输入区与公式区区分。黑白版式使用 Noto Sans CJK SC，目标设备可按自身字体回退显示。

## 验证边界

- 本次完成的是生成引擎的实际重算和 XLSX 导出结构检查，未在桌面 Excel、WPS 或 Google Sheets 中逐一执行兼容性测试。
- CSV 不保留公式、下拉和样式；该限制已写进下载说明，不能把 CSV 的公式列空白当成计算结果。
- 日期提醒只比较输入的日期。岗位截止的具体时刻与时区应从原文单独核对。
- 路线与Offer门槛是核验提醒，不是签证批准、工作资格认证或录用结论。
- 申请台账预留100条记录，其他一般表40条，路线和Offer各12条。超过预留容量须同时扩展表格、公式、验证与汇总范围。
