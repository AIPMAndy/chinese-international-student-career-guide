# 中国留学生求职全局保姆级攻略

**决定去哪就业，走哪条路线，什么时候行动。**

面向在读、即将毕业、已经毕业，以及准备回国或已经回国的中国留学生。按具体国家或地区核验工作资格、招聘窗口、学校资源和申请习惯，再把路线选择落实到材料、投递、面试和 Offer 比较。

## 国家与地区导航

本版提供 **21 个地区路线页（20 个境外国家或地区，加回国路线）**，另有 **20 个明确待补充的地区入口**；登记 **90 条官方来源**。来源数量和导航数量均不代表完整覆盖所有国家、学校、雇主或个人身份分支。

“已核验基础路径”表示本版核对了正文所列官方资料；具体适用条件、读取限制、冲突和缺口见各页及 `data/sources-*.json`。核验日期不是政策有效期，申请前仍应核对现行原文。

## 项目边界与证据

本项目在只读查阅已有求职项目后独立建设，新增留学生的跨地区路线、四类日期、身份条件核验、当地资源和回国衔接。具体查阅版本与差异见[仓库查重记录](docs/repository-audit.md)。本册负责通用路线，AI、产品、商科等专业能力训练由独立专题承担；地址核实存在后再连接。

公开内容不使用未经核实和授权的学校、客户、Offer、薪资或成功率案例。作者背景与服务经历由作者提供；本版没有用虚构个案填补实操内容。

验证材料包括：[模板验证](docs/template-validation.md)、[网站静态验证](website/static-validation.json)、[窄视口验证](website/mobile-validation.json)、[地区导航验证](website/coverage-validation.json)、[PDF验证](docs/pdf-validation.json) 和 [编辑审校](docs/editorial-review.md)。浏览器、PDF、链接的实际检查范围与未完成项以对应记录为准。

## 本地阅读、构建与贡献

网站构建只依赖 Python 标准库，无 npm、外部字体或在线数据库依赖：

```bash
python3 scripts/build_site.py
python3 website/check_links.py
python3 -m http.server 8000 --directory dist
```

然后打开 `http://127.0.0.1:8000/`。完整复现、PDF、工作簿、GitHub 首次发布和可选 GitHub Pages 部署见[构建与发布文档](docs/build-and-publish.md)。

欢迎按[贡献规范](CONTRIBUTING.md)补充地区与纠错。提交政策改动时，应同时给出地区、申请人类别、官方原文、发布日期或生效日期（如有）、本次核验日期、结论与已知例外。发现冲突应保留冲突，无法确认时降为待核验。
