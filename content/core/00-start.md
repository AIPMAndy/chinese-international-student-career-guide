# 从你现在的位置开始

留学生求职，先解决三件事：你能在哪里合法工作，哪一轮招聘接受你的毕业日期，你还有多少准备时间。简历和面试，放在这三件事之后。

这本手册面向在读、毕业前、毕业后和准备回国的中国留学生。覆盖北美、欧洲、亚洲、大洋洲的部分国家与地区，以及回国求职；非洲和南美洲不在本项目范围。地区导航展示实际核验深度，不代表已经核验每一个国家、学校、雇主或个人身份。

## 四个起步入口

| 当前状态 | 今天先做 | 本周应得到 |
|---|---|---|
| 在读，距离毕业还有较长时间 | 查课程结束日、实习限制、Career Service 权限 | 一条主路线、一条备选路线、当地实习核验清单 |
| 即将毕业 | 把毕业日期、许可申请窗口和招聘截止日放进同一张表 | 带最早截止日的倒排计划 |
| 已毕业，仍在境外 | 先确认当前停留与工作权利、剩余现金和离境节点 | 可执行的求职期限与切换条件 |
| 已回国或准备回国 | 查目标雇主的应届生范围、到岗条件和认证要求 | 校招/社招两条清单与回国衔接表 |

“毕业前”是任务入口，不是法定身份。课程完成、学校确认完成、学位授予、毕业典礼、签证到期，可能是不同日期。全部分开记录。

## 第一小时：建立你的事实卡

**准备什么：** 学校官方课程信息、现有许可上的条件、可用现金、三条感兴趣的招聘原文。证件原件留在本人安全设备，不上传到公开仓库。

**具体怎么做：** 在路线决策表填入学习地、学位层级、课程结束时间、学位证日期、当前身份、现有工作权利、最早可入职时间、语言、目标岗位和预算。不能确定的字段写“待确认”，不要凭同学经历填“可以”。

**得到什么：** 一页事实卡。上半页只写已有证据，下半页写待确认的问题、负责答复的人和最迟确认时间。

**如何验收：** 一个不认识你的人看完后，能说出你目前能申请什么、最急的问题是什么。每个硬条件都有来源或明确的待核标记。

**卡住怎么办：** 身份问题问学校国际学生办公室或政府指定渠道；岗位范围问雇主；材料与申请策略问 Career Service。不要把这三种问题混成一句“我能不能留下”。

## 七天最小行动

1. 第一天：完成事实卡，圈出最早的硬截止日。
2. 第二天：对比留当地、第三地和回国三条路线。
3. 第三天：采集目标地区同一类岗位的真实招聘信息，先做五条深读。
4. 第四天：做一份定向简历和一页经历证据表。
5. 第五天：预约一次学校服务，发出两封有具体问题的校友联系邮件。
6. 第六天：提交首批确实符合门槛的申请，保存回执。
7. 第七天：复盘卡点，更新路线和下一周计划。

这里的数量是行动建议，不是录用公式。如果许可或招聘窗口即将结束，先处理硬截止日，再安排训练。

正文用于理解判断，地区页用于查具体差异，工作簿用于记录自己的决策。PDF 适合阅读与打印；网站提供地区筛选、章节阅读和下载。免费内容完整开放，无需先加微信。

本册负责通用路线和申请流程。AI、产品、商科等专业能力训练属于后续独立专题；在专题地址实际存在并核验之前，不放占位链接。
