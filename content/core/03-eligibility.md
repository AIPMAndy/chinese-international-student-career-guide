# 逐行读招聘原文，先过资格关

同一家跨国公司，不同国家、岗位和项目的工作资格要求也可能不同。雇主有担保资质，不代表该职位提供担保；没有写担保，也不代表一定提供或一定不提供。

## 一条岗位拆成八组字段

| 字段 | 要回答的问题 | 保存什么证据 |
|---|---|---|
| 招聘主体与工作地 | 谁签合同？实际在哪工作？ | 官方职位编号、地点和主体 |
| 招聘类别 | 实习、graduate、entry level 还是 experienced？ | 招聘类别原文 |
| 毕业条件 | 按课程完成、学位授予还是入职时在校判断？ | 日期范围与计算依据 |
| 必须条件 | 哪些是 required / essential / minimum？ | 对应的真实能力或证书 |
| 优先条件 | 哪些是 preferred / desirable？ | 已有证据和可补缺口 |
| 工作资格 | 现在能否合法工作？受哪些限制？ | 许可类别、期限与允许范围 |
| 未来担保 | 入职后是否需要雇主办理？该岗位是否支持？ | 岗位说明或招聘方答复 |
| 申请方式 | 截止何时？评估能否用AI？材料格式？ | 官方流程、规则与回执 |

## 两个常见问题不是一回事

“现在是否有权在这里工作”和“现在或将来是否需要担保”要分开回答。临时毕业生许可可能使前者在特定期限和条件下为真，但不一定使后者为否。先用本人条件核对，再依据表单的具体定义填写。

不要为了进入下一页随意选 Yes/No。系统只有二选一、你的情况复杂时，向招聘方询问该字段的定义，保留回复；不能假装已有永久工作资格。

## 资格核对五步

**准备什么：** 完整 JD、岗位编号、学校证明、现有工作许可条件、目标地官方说明。

**具体怎么做：** 先复制与自己相关的短条款到私人资格表，逐条填“原文是什么 / 我的事实 / 对应证据 / 是否符合 / 未解决问题”。对冲突信息按岗位原文、雇主解释和主管机关规则分别核实，不能用其中一种代替另一种。

**得到什么：** 一张能决定“现在投、先问、换职位”的资格表。对担保问题最多写“岗位明确支持 / 明确不支持 / 未说明”，不要推测成确定结论。

**如何验收：** 所有最低门槛都已有对应事实，或明确列为待澄清；简历、网申和邮件里的毕业日期、经验、资格说明一致。

**卡住怎么办：** 用模板询问：“For requisition [ID], does this role consider applicants holding [accurate status], and is employer sponsorship available when that permission ends?” 只填真实、必要的信息。没有回复时保留未知，并继续其他已确认可行的岗位。

## 官方招聘页的实际读法

华为校园招聘的官方检索摘要把国内本科硕士和海外高校毕业生的毕业范围分别列出。直接打开的动态页面未返回可读正文，本版按部分核验记录。这个例子说明：校招资格要按企业、本届、学位与地域读，不能用统一的“毕业两年内都算应届”替代；投递前重新打开具体岗位确认。[S-CN-03](https://career.huawei.com/cn/campus-recruitment)

腾讯海外招聘 FAQ 把海外岗位入口、当地工作许可与在校要求分开说明。读者应继续点击具体岗位核验，而不是把总部政策复制到所有国家。该页面部分内容依赖动态加载；本版核对到官方检索摘要，具体职位仍须重新打开确认。[S-CN-04](https://careers.tencent.com/zh-cn/faqdetail.html)

## 三种立即停止的误读

“学校在名单里”不能替代对课程、学习时长和个人申请日期的核对。“雇主招国际生”不能替代对当前岗位担保范围的核对。“招聘顾问说没问题”不能替代主管机关对工作权利的规则。

资格核验不是为了少投，而是把时间留给真正有机会推进的申请。
