# 中英文材料：一套事实，多种表达

先建立真实经历底稿，再为不同岗位和地区调整呈现。不要分别写两套互相矛盾的中文、英文履历。

## 建立材料清单

| 材料 | 内容要求 | 完成凭证 |
|---|---|---|
| 事实底稿 | 任职/学习日期、角色、真实任务、结果与证据 | 本人能解释并核对 |
| 定向简历 | 目标岗位、对应经历、准确日期与联系方式 | 与JD逐项对应、可选中文或英文 |
| Cover letter / 动机信 | 为什么该岗位、你有什么证据、为何适合 | 每封有明确岗位与公司依据 |
| 项目或作品集 | 背景、个人贡献、方法、结果、限制 | 链接可开，公开权限正确 |
| 学历与成绩材料 | 学校正式名称、学位、预计或已授予日期 | 与正式证明一致 |
| 推荐人 | 已获同意的联系与关系 | 已确认愿意提供推荐 |
| 资格补充 | 仅按申请阶段要求提供必要文件 | 通过雇主安全渠道提交 |

简历页数、照片、签名、成绩单和附件顺序没有全球统一答案。先看岗位指示，再看当地学校职业中心的指南。没有要求时，优先清晰、可检索、便于筛选，避免把大幅照片或复杂图表当成主要内容。

## 五步做出可投递材料

**准备什么：** 一条资格已核对的 JD、真实经历底稿和当地材料要求。

**具体怎么做：** 用 JD 的任务排序经历。每条经历尽量说清“在什么背景下，我做了什么，产生什么可核验结果”。英文使用自己能解释的表达；专有名词和学位名称按官方译名。中文避免把陌生海外头衔直译成国内更高级别。

**得到什么：** 可编辑源文件、提交版本，以及一份字段一致性记录。建议文件名包含姓名、岗位类别、语言和版本日期，避免使用“最终版2真的最终”。

**如何验收：** 打开导出的文件，检查文字能否选择复制、链接能否访问、页面是否完整；请另一个人用30秒说出你申请什么岗位、最强的两项证据是什么。

**卡住怎么办：** 经历少时，用课程、研究、校内工作和个人项目提供证据，并清楚标明性质；语言不自然时请学校顾问反馈，AI只做表达建议，不能增加事实。

## 中英文一致性检查

核对学校名、学位、时间、雇主、职位、项目归属、指标单位和个人贡献。英文的 internship、part-time、contract、research project 不应在中文里全部写成全职工作。

日期统一使用不会混淆的格式，例如英文月名加年份，或 ISO 日期。预计毕业要写预计；已完成课程但未获学位，分别说明，不提前宣称已取得学位。

## 作品集与附件自查

用退出登录后的浏览器打开作品集。确认访问者不需要申请你的私人网盘权限；页面没有客户隐私、内部截图或可用密钥。不能公开的成果，用获准的摘要描述，说明公开范围。

不要在首轮简历里主动堆放护照号、完整住址、签证扫描件和家庭资料。工作资格可以先准确说明类别与条件；需要证明时按雇主正式渠道提供。

提交前检查网申自动解析的教育和工作字段。解析错误要手工更正，不能只看附件上传成功。
